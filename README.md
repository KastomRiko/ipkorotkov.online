# ipkorotkov.online

Репозиторий содержит снимок WordPress-сайта и исходники собственных компонентов проекта.

## Структура

- `index.php`, `wp-admin/`, `wp-includes/`, `wp-content/` — WordPress и его содержимое.
- `wp-content/themes/korotkov-dark/` — собственная тема сайта Korotkov Dark.
- `korotkov-seo-factory/` — **основная папка разработки Korotkov SEO Factory, версия 0.8.1**. Изменения плагина вносятся сюда.
- `wp-content/plugins/korotkov-seo-factory/` — старая копия плагина 0.7.0, оставленная в снимке WordPress. Это не исходник для дальнейшей разработки; перед заменой на сервере требуется отдельная проверка и выпуск пакета.
- `dveri/index.html` — отдельная HTML-страница проекта дверей ENTRO.
- `archive/` — архивные файлы, не используемые как главная страница сайта или текущий пакет плагина.
- `.github/workflows/` — автоматическая проверка синтаксиса PHP исходников плагина.

## Важные правила

1. Не добавлять в Git `wp-config.php`, API-ключи, пароли, приватные ключи, дампы БД и журналы.
2. Не удалять массово `wp-admin/`, `wp-includes/`, плагины или темы: репозиторий пока хранит полный снимок WordPress, и эти файлы могут быть частью процесса развертывания.
3. Не редактировать копию SEO Factory в `wp-content/plugins/` как основную. Разработка ведётся в `korotkov-seo-factory/`.
4. Перед публикацией плагина на рабочем сайте собрать и проверить отдельный ZIP из основной папки. Само наличие исходников в GitHub не обновляет сайт.
5. `wp-content/uploads/` уже содержит ранее добавленные в Git медиафайлы. Правило в `.gitignore` предотвращает добавление новых загрузок, но не удаляет старые файлы из истории Git.
6. Корневой `index.php` — входная точка WordPress. Страница хостинговой заглушки перенесена в архив, чтобы не конкурировать с ней за адрес главной страницы.

## Ветки и Pull Requests

Изменения SEO Factory оформлены последовательной цепочкой Draft PR. Сначала проверяется и принимается самый нижний PR, затем следующий по цепочке. Ни один из этих PR не следует сливать в `main` автоматически: сначала нужно проверить итоговый diff и успешные проверки.

Рабочий PHP workflow проверяет файлы в `korotkov-seo-factory/`. Проверка синтаксиса не заменяет функциональные тесты, тесты БД или проверку на копии сайта.
