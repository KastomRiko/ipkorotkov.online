# Korotkov SEO Factory

Отдельный WordPress-плагин для проекта ipkorotkov.online.

## Текущий статус: 0.1.0 — безопасная основа

В этой версии добавлены:

- отдельная административная страница SEO Factory;
- таблицы для заданий, ключевых фраз, кластеров, SERP, страниц и журнала;
- ежедневное событие WordPress Cron;
- настройки внутренних ограничителей Wordstat и Search API;
- поля для Folder ID и API-ключа сервисного аккаунта;
- фиксированный проектный бюджет 4 000 ₽ и порог остановки 3 800 ₽.

## Что намеренно НЕ включено

Эта версия не выполняет внешние запросы к Яндексу, не отправляет данные в Qwen и не публикует страницы. Ежедневный обработчик только записывает событие в журнал. Это сделано специально: сначала нужно проверить API-контракты, квоты, тарифы и применимость бонусного баланса, чтобы исключить случайные расходы.

## Следующие этапы

1. Реализовать клиент Yandex Search API с безопасной очередью и кэшированием.
2. Добавить общий дневной счётчик Wordstat и ограничение частоты.
3. Добавить учёт стоимости по подтверждённым тарифам и аварийную остановку.
4. Реализовать экспорт заданий и импорт результата из веб-интерфейса Qwen.
5. Добавить кластеризацию, проверку дублей и качества посадочных страниц.
6. Подключить публикацию в WordPress со строгими автоматическими проверками.

## Принятые ограничения проекта

- Регион исследования: вся Россия.
- Wordstat: внутренний предел по умолчанию — 20 запросов в сутки суммарно по всем методам; интервал — не менее 5 секунд.
- Search API: внутренний интервал — не менее 2 секунд.
- Параллельные задачи: одна.
- Бюджет: 4 000 ₽; остановка платных операций до превышения 3 800 ₽.
- Qwen: только ручной обмен файлами через chat.qwen.ai, без браузерной автоматизации и без Qwen API.
- Публикация: автоматическая после прохождения проверок, без ручного подтверждения каждой страницы.

Все внутренние ограничения являются предохранителями проекта, а не официальными квотами Яндекса.
