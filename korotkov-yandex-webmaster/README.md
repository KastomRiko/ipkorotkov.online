# Korotkov Yandex Webmaster

Версия: 1.0.0

Read-only интеграция WordPress с официальным API Яндекс.Вебмастера.

## Установка

1. Установите ZIP через WordPress → Плагины → Добавить плагин → Загрузить плагин.
2. Активируйте плагин.
3. Откройте Настройки → Яндекс.Вебмастер.
4. Вставьте OAuth-токен и сохраните.
5. Нажмите «Проверить доступ к API».

## Что проверяет

- GET /v4/user — доступность OAuth-токена и user_id.
- GET /v4/user/{user_id}/hosts — список сайтов аккаунта, URL, подтверждение и права.

## Безопасность и ограничения

- Только read-only запросы к API; публикации, переиндексации и изменения настроек не выполняются.
- Токен не выводится обратно в HTML и не записывается в Git.
- Настройки доступны только пользователям с manage_options и защищены nonce.
- Для более строгого хранения можно определить KOROTKOV_YANDEX_WEBMASTER_TOKEN в wp-config.php. При наличии константы поле редактирования отключается.
- В режиме настройки токен хранится в таблице wp_options WordPress; доступ к серверу/БД администратора сайта остаётся доверенной границей.
- Не вставляйте токен в URL, публичные логи, тикеты или репозиторий.
